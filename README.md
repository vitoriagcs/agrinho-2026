# AgroForte do Futuro Sustentável 🌾🚀

Este é o repositório do site institucional da **AgroForte do Futuro Sustentável**, uma plataforma digital desenvolvida para apresentar soluções agrícolas inteligentes que unem inovação, tecnologia e sustentabilidade para promover um futuro mais verde e produtivo.

## 📋 Sobre o Projeto

O site tem como objetivo divulgar as práticas e tecnologias aplicadas pela AgroForte no agronegócio moderno, destacando o uso de ferramentas de alta performance com baixo impacto ambiental.

O projeto é uma landing page simples, moderna, responsiva e estruturada de forma semântica em HTML5 e CSS3.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo (`<header>`, `<nav>`, `<section>`, `<footer>`).
- **CSS3:** Estilização e layout responsivo (recomenda-se o uso de Flexbox ou CSS Grid para o arquivo `style.css`).
- **Google Fonts:** Utilização da fonte institucional *Roboto*.
- **Imagens (Unsplash):** Integração de imagens de alta qualidade voltadas ao ecossistema agro-tecnológico.

## 🗂️ Estrutura de Seções do Site

1. **Cabeçalho (Header):** Título principal da marca.
2. **Menu de Navegação (Nav):** Links internos de rolagem suave para navegação na página (*Sobre*, *Tecnologia*, *Contato*).
3. **Sobre Nós:** Introdução sobre a missão da empresa com imagem ilustrativa de um campo sustentável.
4. **Tecnologia Sustentável:** Seção em formato de *cards* apresentando as principais inovações:
   - Drones Agrícolas (Monitoramento em tempo real)
   - Irrigação Inteligente (Economia de recursos hídricos)
   - Energia Renovável (Uso de matrizes solares e eólicas)
5. **Contato:** Informações de atendimento (E-mail e Telefone).
6. **Rodapé (Footer):** Direitos autorais e ano de vigência.
